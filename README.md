# Age of the Saiyan

A Dragon Ball–inspired RPG built with **Godot 4.0 (C# / GDScript)**.

![Title Screen Preview](Screenshot%202023-06-18%20171807.png)

---

## Engine / Framework

| Item | Detail |
|------|--------|
| Engine | Godot 4.0 |
| Languages | C# (menus / intro), GDScript (UI milestone screens) |
| Rendering | Forward Plus |
| .NET Assembly | `Age of the Saiyan` |

---

## Requirements

- **Godot 4.0** with **.NET / C# support** enabled (the "Mono" build or the standard 4.0+ build with .NET SDK installed)
- **.NET SDK 6.0 or later** (required to compile the C# scripts)
- No other external tools are needed; all addons are bundled in the `addons/` folder

---

## Setup & Running Locally

1. Clone the repository:
   ```
   git clone https://github.com/ant3869/Age-of-the-Saiyan.git
   ```
2. Open **Godot 4.0** (with .NET support).
3. Choose **Import** → select the `project.godot` file at the repository root.
4. Wait for the editor to finish importing assets and compiling C# scripts.
5. Press **F5** (or the **Play** button) to run the project.

The game starts at `scenes/IntroDisclaimer.tscn` as defined in `project.godot`.

## Current Game Flow

```
IntroDisclaimer  →  IntroLogo  →  Main Menu
                                      │
                                  [ Start ]
                                      │
                                  Auth Screen (Login / Create Account)
                                      │
                               [ LOGIN button ]
                                      │
                                  Squad & Battle Screen
```

| Step | Description |
|------|-------------|
| Intro Disclaimer | Plays `GameDisclaimer2.ogv` video; auto-advances |
| Intro Logo | Plays `IntroLogo2.ogv` video; auto-advances |
| Main Menu | Background art + three buttons: **Start**, **Options**, **Quit** |
| Auth Screen | Login form and Create Account form (stub — any input is accepted) |
| Squad & Battle Screen | Squadron roster panel + Battle panel with mock data |

---

## How to Reach the Auth / Login Screen

1. Launch the game.
2. Let both intro videos play through (or skip is not yet wired).
3. On the **Main Menu**, click **Start**.
4. The **Auth Screen** (`MainAuth.tscn`) opens, showing the Login form.

### Navigating the Auth Screen

| Action | How |
|--------|-----|
| Switch to Create Account | Click **"Create New Account"** link at the bottom of the login form |
| Return to Login | Click **Back** on the Create Account form |
| Proceed to game | Fill in any Commander ID and Password, then click **LOGIN** |

> **Note:** Authentication is a stub. No backend exists yet. Any non-empty Commander ID and Password will be accepted and transition you to the Squad & Battle screen.

---

## How to Reach the Squad & Battle Screen

After logging in (see above), the game transitions automatically to `MainSquadBattle.tscn`.

### Squad & Battle Screen Controls

| Element | Description |
|---------|-------------|
| Squadron panel (top) | Roster table showing mock warriors with HP/KI/Role/Status columns |
| RECRUIT WARRIOR / TRAINING ROOM / SQUAD FORMATIONS buttons | Display an action log entry in the Battle panel (stub) |
| STATS / SKILLS / ABILITIES / EQUIPMENT / SQUADRON / PLANETS / MARKET tabs | Navigation tabs (stub — not yet wired to sub-views) |
| Battle panel (bottom) | Shows Player vs Enemy stat cards and a scrollable combat log |
| Player action buttons | Selectable combat actions (stub — selection is logged, no turn logic yet) |
| Enemy action buttons | Displayed but not interactive |
| Squad bonus labels | ATTACK / DEFENSE / EXPERIENCE labels (values not yet calculated) |

All data shown is **mock data** generated by `scripts/ui_milestone/data/mock_data.gd`.

## Known Limitations / Incomplete Areas

- **No real authentication** — the login form is a visual stub; any input proceeds.
- **No save/load system** — all data is mock/in-memory and resets on restart.
- **No combat logic** — the battle screen displays stats and logs messages, but no turn-based system is implemented.
- **Many scenes are disconnected** — character sheet, character creation, stat assigner, and others exist but are not reachable from the main flow.
- **Intro videos are required** — if the `.ogv` files are missing the game will error at startup; press **F8** or check the editor console.
- **Options menu is empty** — the Options button on the main menu does nothing.
- **Tab buttons are stubs** — the STATS/SKILLS/ABILITIES etc. tabs in the Squad screen are not wired to any content.
- **Case-sensitive path issue (Linux)** — intro scenes live in `Scenes/` (capital S) while `project.godot` references `res://scenes/` (lowercase). This works on Windows but may fail on a case-sensitive Linux filesystem. Run via the Godot editor on Windows or adjust paths if needed.
